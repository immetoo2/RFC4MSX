## MSX4

A new design to wake up the seven dwarfs and removing the "byte from the apple".  
Based a bit on the MSX but upgraded to 18 bit native and turned inside out.

Hardware;
* Replace the bit(1 bit) to octal(3 bit)
* Replace the byte(8 bit) to tord(18 bit)
* New number formats for native 144 bit ALU
* Replace the bus master with dipavali 4D matrix
* Kernel and BASIC code can run as FPGA device

Software;
* Replace "MSX binary BASIC" with true I18N solution for API and source code
* Replace native types with enum terminators for abacus and safe data programming
* Replace ISO locale with numeric tree based lingua slug (~32k defined languages)
* Replace trust model of internet to boot OS from network
